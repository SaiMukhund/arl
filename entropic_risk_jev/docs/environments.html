Overview

All three are fully-specified tabular MDPs over true states, exposed as explicit transition/reward tensors P[s,a,s'] and R[s,a,s']. Because the model is known, exact entropic value iteration, distributional DP and exact policy evaluation are all available as ground truth. Each state also renders to a yev0-4b / Jev text prompt.

Reward on a successful move to state d is always R = −cost(a) + (goal_reward if d is GOAL else 0); a failure transition pays the page's negative catastrophe cost. Terminal states self-absorb with zero reward.

Shared action model

Every non-terminal page offers the same three actions. They occupy distinct risk/cost niches, so as the risk parameter β rises the optimal policy climbs the ladder FAST → SAFE → ASK.

a = 0

FAST

Advance fast_step (=2) layers. Full failure probability. Cheapest.

a = 1

SAFE

Advance 1 layer. Failure prob × p_safe_factor (=0.15). Small penalty.

a = 2

ASK

Advance 1 layer. Failure prob = 0 (escalate to System 2). Fixed cost.

RiskyCheckout src/env.py

A 6-step linear chain — the minimal setting that makes risk-neutral and risk-averse policies differ. Catastrophes are rare (p=0.02) but expensive, with a cost gradient that rises each stage, so risk aversion drops FAST on the costliest stages first.

Reward / transition function

# states: 0..5 = stages, 6 = GOAL, 7 = CATASTROPHE  (both terminal)
# advance(i, step) = GOAL if i+step >= 6 else i+step

FAST  p = p_cat[i]                       dest = advance(i, 2)
      P[i, FAST, CATASTROPHE] += p       R = -cost_cat[i]
      P[i, FAST, dest]        += 1 - p   R = -step_cost (+goal_reward if dest=GOAL)

SAFE  p = p_cat[i] * 0.15              dest = advance(i, 1)
      P[i, SAFE, CATASTROPHE] += p       R = -cost_cat[i]
      P[i, SAFE, dest]        += 1 - p   R = -step_cost - safe_penalty (+goal if dest=GOAL)

ASK   dest = advance(i, 1)
      P[i, ASK, dest] = 1.0                R = -ask_cost (+goal_reward if dest=GOAL)
Config: goal_reward=12, step_cost=0.1, safe_penalty=0.5, ask_cost=1.2, fast_step=2.

RiskyWeb src/env_web.py

A layered branching DAG (8 layers × 3 branches). Pages are typed; danger grows in later layers, the next page is sampled (stochastic branching), and both failure probability and cost carry jitter so a policy must generalise over danger rather than memorise states.

Danger assignment & branching

# per page s of type t, with jitter U(.):
p_cat[s]  = base_p(t) * (1 + U(-0.30, +0.30))     # p_jitter
cost_cat[s] = base_c(t) * (1 + U(-0.25, +0.25))   # cost_jitter

# successor of advancing `step` layers (branching):
target = layer(s) + step
if target >= n_layers:  dests = [GOAL],      probs = [1.0]
else:                   dests = pages(target), probs = Dirichlet(α=0.7)

Reward / transition function

# action spec: FAST(step=2, p=p_cat[s]) SAFE(step=1, p=p_cat[s]*0.15) ASK(step=1, p=0)
for a in {FAST, SAFE, ASK}:
    if p > 0:
        P[s, a, CATASTROPHE] += p          R = -cost_cat[s]
    for (d, dp) in successor(s, step):     # branches
        P[s, a, d] += (1 - p) * dp
        R[s, a, d]  = -cost(a) + (goal_reward if d=GOAL else 0)
Config: goal_reward=15, step_cost=0.1, safe_penalty=0.4, ask_cost=1.0, branch_concentration=0.7.

RiskyFlow src/env_v2.py

The richest environment (10 × 4) and the main benchmark. It has graded failures (a minor and a major terminal), semantic visible elements that drive danger, a hidden per-page severity multiplier, and a noisy observable hint — so the three risk measures genuinely disagree and the agent must infer risk.

Danger assignment (per page s)

# emax = max element multiplier on the page;  sev ∈ {0.6, 1.0, 1.4} is HIDDEN
q_minor[s] = min(0.5,  q_minor_base * sev)
q_major[s] = min(0.4,  q_major_base * emax * sev)
c_minor[s] = min(25,   c_minor_base * (0.8 + 0.4*sev))
c_major[s] = min(90,   c_major_base * emax * (0.7 + 0.5*sev))

# observable (noisy) danger meter — severity itself is NOT observed:
obs_hint[s] = normalize( sev * emax * (1 + U(-0.5, +0.5)) )   # in [0,1]

Reward / transition function

# fmul: FAST=1.0  SAFE=0.15  ASK=0.0   (scales BOTH fault probabilities)
for a in {FAST, SAFE, ASK}:
    q_min = q_minor[s] * fmul
    q_maj = q_major[s] * fmul
    if q_min > 0:  P[s,a,CAT_MINOR] += q_min   R = -c_minor[s]
    if q_maj > 0:  P[s,a,CAT_MAJOR] += q_maj   R = -c_major[s]
    p_ok = 1 - q_min - q_maj
    for (d, dp) in successor(s, step):          # Dirichlet(0.7) branching
        P[s,a,d] += p_ok * dp
        R[s,a,d]  = -cost(a) + (goal_reward if d=GOAL else 0)
Config: goal_reward=15, severity_levels=(0.6, 1.0, 1.4), obs_hint_noise=0.5, cost_minor_cap=25, cost_major_cap=90. Terminals: GOAL, CAT_MINOR, CAT_MAJOR.
